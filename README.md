# YoRHa Wardrobe Collection - Multilingual Localization (RU / EN / ZH)

This is a localization add-on for the **YoRHa Wardrobe Collection** mod (for Phantom Blade Zero). 

It adds full multilingual support for the mod's UI, descriptions, and settings menus. The text will **automatically switch** based on the language selected in the game.

## Features
- Full Russian (RU), English (EN), and Chinese (ZH) translations.
- Language switches automatically with the game settings.
- Fixes the issue where text would not display or show placeholders on non-Chinese locales.
- Includes translated `.modsmenu.json` files for the Mods Menu interface.

## Prerequisites
- You must have the original **YoRHa Wardrobe Collection** mod installed.
- UE4SS, Mods Menu, and the official Bridge must be installed and working.

## Installation
1. Ensure the game is closed.
2. Download this repository as a ZIP (click the green **Code** button -> **Download ZIP**).
3. Extract the archive.
4. Copy the contents of the extracted folder into your game's mod folder. 
5. When prompted, **replace** the existing files with the new ones.
6. Launch the game and enjoy!

## Note
The files in this repository only contain scripts, configuration, and localization data. They do not contain the 3D models or textures (`.pak` / `.utoc` / `.ucas` files), as those belong to the original mod author.
